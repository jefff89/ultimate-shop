| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Information Disclosure | route `loader` prefetch error surfacing internals to the public landing page | mitigate | `ensureInfiniteQueryData` only fetches the contract-validated page (CatalogProductCardPageSchema.parse at the seam); the loader does not echo raw errors into the page. End-of-list/loading copy is static strings, never server error text |
| T-03-07 | Denial of Service | unbounded retained pages on the live page during deep scroll | mitigate | `maxPages: 6` from Plan 01's factory applies on the real route (GRID-03); checkpoint step 4 visually confirms the cap in devtools |
| T-03-02 | Tampering (XSS) | product text rendered on the public route | mitigate | Inherited from Plan 01 — JSX children only, no `dangerouslySetInnerHTML`; SafeImage for images. This plan adds no new raw-HTML render path |
| T-03-08 | Spoofing/Tampering | duplicate/forged page-1 request on hydration | accept | Mitigated by design: the loader and client share the identical `catalogInfiniteQueryOptions` queryKey, so hydration satisfies the client query — no second page-1 request is issued; checkpoint step 3 verifies. Cursor validation for subsequent pages is owned by the Phase 2 seam codec |
| T-03-SC | Tampering | npm/bun installs | accept | No new dependencies added in this plan. No install task → no slopcheck checkpoint required |
