## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Denial of Service | unbounded `limit` on rail routes | mitigate | `boundRailLimit` clamps to `[1, MAX_PAGE_SIZE]` with non-finite/fractional guard + global ThrottlerGuard (100/60s) |
| T-06-06 | Information Disclosure | rail items leaking internal columns (createdAt, basePrice, variant data) or category tree/parent | mitigate | Reuse field-by-field `toCard` for products; project only id/name/slug for categories and validate via `CategoryRailItemSchema.parse()`; no relation/tree hydration |
| T-06-07 | Tampering | SQL injection via flag column / limit | mitigate | Flag filter uses a fixed allowlist of column names (`isFeatured`/`isTrending`) bound via named params; `limit` is a clamped JS integer passed to `.limit()`, never interpolated |
