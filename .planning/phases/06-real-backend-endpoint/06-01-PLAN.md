## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | `cursor` query param flowing into the keyset WHERE | mitigate | `decodeCursor` validates the decoded tuple shape and throws `InvalidCursorError` (-> 400); the tuple is bound as named params `:cAt`/`:cId`, never string-interpolated into SQL (Security V5) |
| T-06-02 | Denial of Service | huge/`Infinity`/`NaN` `limit` | mitigate | Mock-identical clamp to `[1, MAX_PAGE_SIZE]` with non-finite/fractional guard (CAT-03) + existing global ThrottlerGuard (100 req/60s) |

| T-06-04 | Tampering | SQL injection via `limit`/`cursor` | mitigate | Parameterized QueryBuilder bindings only (`:active`, `:cAt`, `:cId`); the size is a clamped JS integer passed to `.limit()`, not interpolated |
| T-06-SC | Tampering | npm/bun installs | accept | No new packages installed this phase (RESEARCH Package Legitimacy Audit: zero installs; zod approved in Phase 1).
